## 1. 홈이 답해야 할 질문 (우선순위 순)

1. **최근에 무엇을 했고, 어디서 멈췄나** → 최근 활동 · 진행 중 조사 · 열린 질문
2. **어떤 조사가 있고, 각각의 결론은 무엇인가** → 조사 카드 + 결론 1줄
3. **분야를 넘어 다시 쓸 수 있는 해법은 무엇인가** → 겹치는 패턴 카드(결론 포함) · 겹치는 레퍼런스
4. **이 라이브러리에 무엇을 물을 수 있나** → 발견 검색 · Claude 프롬프트
