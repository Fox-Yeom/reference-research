# reference-research (베타)

Claude Code 플러그인입니다. 서비스를 기획할 때 필요한 **레퍼런스 조사**를 Claude에게 맡깁니다.

- 비슷한 서비스·경쟁 화면·디자인 사례·강의를 찾아 **실제 화면을 캡처**합니다.
- 발견한 내용은 **출처가 붙은 주장**(C#)으로 남기고, 출처 수로 신뢰도를 계산합니다.
- 카테고리마다 **비교 보드**(HTML)를 만듭니다: 한눈에 보기 · 패턴 비교 · 레퍼런스 화면 · 발견과 근거.
- 한 번 모은 레퍼런스는 다른 조사에서 다시 쓰고, 30일이 지났으면 새로 캡처해 바뀐 점을 기록합니다.
- 모든 자료는 **내 컴퓨터**(`~/references`)에만 쌓입니다. 외부로 보내지 않습니다.

## 필요한 것

| 항목 | 필수 | 설명 |
|---|---|---|
| Claude Code | 필수 | 최신 버전 |
| Node.js 20 이상 | 필수 | `node --version`으로 확인 |
| Python 3 + Pillow | 권장 | 이미지 미리보기·스크롤 캡처. `pip3 install pillow` |
| 캡처 브라우저 | 권장 | **Aside**(로그인된 내 브라우저로 캡처) 또는 **Google Chrome**(로그인 없이 캡처). 둘 다 없으면 텍스트 자료만 수집 |
| git | 권장 | 라이브러리 변경 이력 보관 |

## 설치

이 저장소는 비공개입니다. 먼저 초대를 수락하고, 터미널에서 GitHub 로그인이 되어 있어야 합니다(`gh auth login` 또는 git 자격 증명).

Claude Code 안에서:

```
/plugin marketplace add Y-jae-heon/reference-research
/plugin install reference-research@reference-research-beta
```

설치 후 Claude Code를 다시 시작하고, 아래처럼 말해 보세요.

```
레퍼런스 조사 도구 상태 점검해줘   (→ ref doctor 실행)
```

⚠ 표시가 나온 항목은 안내된 명령으로 해결할 수 있습니다. 처음 한 번 `ref setup --git`으로 라이브러리를 git 저장소로 만드는 것을 권장합니다.

### 선택: 의미 검색(임베딩)

관련 레퍼런스 추천과 의미 기반 검색을 쓰려면 한 번 설치합니다(약 700 MB, `~/.reference-research`에 저장).

```
ref setup --embeddings
```

없어도 조사·캡처·보드는 모두 동작하고, 검색은 글자 일치로만 합니다.

## 써 보기

```
가계부 앱 온보딩 레퍼런스 조사해줘
AI 실무 교육 커리큘럼 만들기 전에 비슷한 강의 비교해줘
지난번 조사에서 한도 표시를 어떻게 하는지 찾아줘   (→ MCP로 라이브러리 검색)
```

보드는 `~/references/<카테고리>/index.html`, 전체 목록은 `~/references/index.html`입니다.

## 업데이트

```
/plugin marketplace update reference-research-beta
```

새 버전이 있으면 설치된 플러그인이 갱신됩니다. 바뀐 점은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.

## 지켜지는 것

- 캡처는 **읽기 전용**입니다. 폼 제출·가입·결제·글쓰기·동의 버튼 클릭은 하지 않습니다.
- Chrome 캡처는 로그인 정보 없이 새 프로필로 실행하고, 끝나면 지웁니다.
- 라이브러리는 내 컴퓨터에만 있습니다. 직접 요청하기 전에는 어디에도 올리지 않습니다(다른 사이트 화면이 들어 있으므로 공개 저장소에 올리지 마세요).

## 알려진 한계 (베타)

- Chrome 캡처는 로그인이 필요한 페이지, 봇 차단이 강한 사이트에서 실패하거나 로그인 화면이 찍힙니다.
- macOS에서 주로 시험했습니다. Windows는 Chrome 경로를 `REF_CHROME`로 지정해야 할 수 있습니다.
- 처음 `ref`를 실행할 때 필요한 패키지(약 80 MB)를 내려받느라 잠시 걸립니다.
